To use this script, either run manually or:

1. Rename the folder containing unsorted videos (by default named after the date of download) to "to_sort"
2. Right click inside this folder (N863A6) and choose Open in Terminal.
3. In the terminal, type "python surveillance_sort.py" You will get an output of files and their new locations.
4. CHECK that the to_sort folder is now empty. If so, delete it. 
5. Repeat this process with the rest of the folders you need to sort. To reuse a command in Terminal you can hit the up arrow key instead of typing "python surveillance_sort.py" every time.
